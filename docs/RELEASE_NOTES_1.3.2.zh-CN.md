# Bingo Send 1.3.2（build 13）待测版

## 首次安装流程

1. 全新安装并首次打开主窗口时，检查真实辅助功能权限；未授权才自动发起一次 macOS 原生授权请求。若系统未显示提示，页面保留「打开系统设置…」作为备用入口。
2. 授权由用户本人完成，返回后自动刷新状态；已授权的提示和按钮移到页面底部默认折叠的「权限与诊断」。授权失效时，顶部引导自动重新出现。
3. 应用范围默认全关闭。运行区明确显示「已授权 · 下一步选择目标应用」，点击按钮可直接定位范围列表。
4. 用户主动启用目标应用后，再选择测试识别或自动发送。授权本身不会启用应用或开始发送。每次启动仍暂停。

首次权限检查的标记与「是否已授权」分别保存和判断：保留偏好重开不会重复请求；真正清空偏好并重置本应用 TCC 后再安装，会重新走首次流程。只清偏好但系统仍实际授权时，不会为了制造弹窗再次请求。

## 验证清单

- 自动化：首次未授权、已授权升级、重复展示、拒绝后重开、手动设置备用入口、暂停时授权刷新、撤权后阻止运行，以及清偏好后重新请求。
- 实际安装：固定最终安装包与签名后，备份并卸载本地副本、清本应用偏好与权限、重新安装；检查首次原生提示、用户授权后的界面收起、目标列表跳转、关闭/重开与不重复提示。
- 本地输入夹具：分别验证测试识别、保留发送、移除发送与暂停；接收计数与正文为证据，不向外部聊天提交测试消息。
- 平台限制：原生提示是否呈现由 macOS 决定；只有隔离测试不能证明系统弹窗已出现。实际通过项见独立验证记录，未执行项目保留为未验证。

本版沿用最多三个口令与既有发送逻辑。安装包仍为 ad-hoc 签名，未经 Apple 公证；签名更新可能需要用户重新授权。Intel 硬件与最低 macOS 运行未在本轮验证。
