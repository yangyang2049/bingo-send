# Bingo Send 1.2.0

[English](RELEASE_NOTES_1.2.0.md) | [简体中文](RELEASE_NOTES_1.2.0.zh-CN.md)

本次增加需主动添加的应用和网站配置预设、常用口令菜单、可选句尾口令移除、黑白应用图标与中英文界面。默认行为仍是新消息以当前唯一启用的口令结尾，文字稳定后触发配置的发送按键，完整正文与口令原样保留；移除模式需单独开启。

## 变化

- 增加 13 个统一列出、可搜索的配置预设：Codex / ChatGPT、Claude / Claude Code、Gemini、Grok、Cursor、HuggingChat、DeepSeek / DeepSeek Harness、ZCode、Kimi、Kimi Code、WorkBuddy、Qoder CN、TRAE CN。预设帮助填写范围，不代表已验证兼容；已知且已安装的原生应用可直接选择，其他桌面应用可手动选择。终端 CLI 不包含在此预设覆盖范围内。
- 网页预设可选择已安装的浏览器，预览并合并允许域名，保留已有条目并启用该浏览器规则；同一浏览器的全部允许网站共用一个发送按键。
- 界面按系统首选语言自动使用英文或简体中文，其他语言回退英文。
- 从 Bingo、Submit、Send、发送、提交、完成、确认、确定中选择一个启用口令，或输入自定义内容。口令匹配仍不区分大小写。
- 增加“发送前移除句尾口令”，默认关闭。只移除匹配的句尾口令及其后的标点和空白，更早的正文、标点和中间的口令均保留；读回核验编辑结果及上下文后再发送。不支持或核验失败时停止并暂停，不发送；编辑中断可能留下已改草稿或选区，请用户检查，不自动恢复旧文字而覆盖新输入。
- 全新安装的应用列表默认全部关闭，默认只检测、发送暂停；已有保存配置不迁移、不覆盖，每次启动仍从暂停开始。
- 图标改为黑色圆角方形底、白色纸飞机。
- 使用指定物理像素尺寸的 `NSBitmapImageRep` 绘制图标，替代 `NSImage.lockFocus()`，避免 Retina 显示比例导致导出的 PNG 尺寸错误。
- 校验全部 10 个标准 macOS 图标的文件名和物理像素尺寸：16、32、128、256、512 点各提供 1× 和 2×。构建时还会把生成的 ICNS 转回 iconset，在签名前再次校验全部图标。
- 发布应用包中若包含仅限本地的测试工具，打包流程会拒绝继续。本地测试编辑器不包含在应用或仓库中。
- 补充替换 ad-hoc 临时签名应用后，旧授权条目失效时只重置本应用辅助功能授权的备选方法。详见[权限排查](USER_GUIDE.zh-CN.md#常见问题)。

## 安装与权限

需要 macOS 13 及以上。下载 `BingoSend-1.2.0-macOS-universal.dmg`，把 Bingo Send 拖入“应用程序”并打开。通用包包含 Apple Silicon 和 Intel 两种架构；Intel 和最低 macOS 版本仍需实机验证。

安装包使用 ad-hoc 临时签名，**未经 Apple 公证**。若 macOS 阻止打开，请按 [Apple 的常规系统设置流程](https://support.apple.com/102445)操作。辅助功能权限必须由你亲自授予当前安装的应用。替换应用后可能遗留失效授权；如果系统开关已开而程序仍提示未授权，请按使用指南排查。

每次启动默认暂停。先确认辅助功能授权，主动选择应用或浏览器范围与一个口令，用一条新消息验证只检测模式，再启用实际发送。全新安装和缺少移除设置的旧配置均默认关闭移除，需在保留模式可用后再单独验证；只检测模式不会编辑。无需安装 Codex 或 Skill。预设列表和操作方法见[使用指南](USER_GUIDE.zh-CN.md#应用和网站预设)。

## 验证状态与限制

1.2.0（build 10）已通过 53 个单元测试（45 个核心测试、8 个应用测试）、arm64/x86_64 通用构建、全部 10 个图标尺寸检查、严格的 ad-hoc 签名校验和 ZIP/DMG 打包检查。ZIP 解包及 DMG 挂载后应用均与构建一致，未包含仅限本地的测试编辑器。当前安装应用来自已验证的 ZIP。

已在安装后的英文界面核对设置、统一预设列表、口令移除预览、网页预设配置窗口和帮助；简体中文设置及统一列表已按系统语言偏好核对。下述自动发送实测属于界面本地化前的 build 9；build 10 仅调整界面，尚未重复两种模式的实际发送测试。

此前的 1.2.0（build 9）已通过 47 个单元测试、通用架构构建、ad-hoc 签名完整性校验和打包检查。可选移除与默认保留两种模式均在独立、仅限本地的 WKWebView 编辑器中通过实际发送测试，并由用户确认自动发送。移除测试后发送次数为 1、输入框清空，正文中间的 Bingo 保留，最后的口令移除；随后保留模式测试将发送次数增加到 2、输入框清空，收到完整的 `保留模式测试 Bingo。`，口令及末尾中文句号均保留。本地测试编辑器不随应用发布，也不包含在仓库中。

1.1.0 的保留模式曾在本地 WKWebView 编辑器和用户 Codex 中实测自动发送成功。本次本地移除测试不代表 Codex 或其他 AI 应用支持移除，增加 13 个配置预设也不代表已验证的 AI 输入框范围扩大。其他应用或网站仍需逐个验证，其输入框必须提供可读取的辅助功能文本和光标信息，移除还要求编辑支持。详见[兼容性记录](COMPATIBILITY.zh-CN.md)。

Bingo Send 不录音、不联网、不保存聊天正文，也不能替输入法结束录音。
