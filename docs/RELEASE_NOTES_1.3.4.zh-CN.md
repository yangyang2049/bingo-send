# Bingo Send 1.3.4

2026-11-01 · macOS 13 及以上 · Apple Silicon / Intel 通用安装包

## 改动

- 发送失败只中止本次尝试，连续失败也保留「自动发送」，后续新输入可以继续处理。
- 不自动重试同一份失败草稿及可能延迟返回的删除结果，不重复删除、不回滚覆盖新输入。
- 删除前遇到继续输入时重新等待；已选中口令时，继续操作前核验原正文完整、光标及上下文。
- 改善编辑器异步更新的核验等待，并在跳过某次尝试时显示具体原因。
- 包含 1.3.x 预览版中的最多三个句尾口令、「暂停／测试识别／自动发送」和首次辅助功能授权引导。

每次启动仍从暂停开始。默认保留完整正文及口令；可选移除只删除最后命中的口令及其后的
标点或空白，更早的重复口令保留在正文中。应用不能结束输入法的录音。

## 验证情况

- 104 项自动测试通过：核心 67 项、应用 37 项，覆盖连续失败、延迟编辑结果、取消和焦点变化等。
- 通用生产构建、临时签名完整性验证通过。
- ZIP 与只读挂载 DMG 内的应用，与用户已授权并确认正常使用的已安装应用为同一份签名二进制。
- 用户确认全新安装弹出原生提示、亲自完成授权并可正常使用。额外的本地编辑器移除、延迟、
  连续失败及连续语音测试未完成，已按用户要求停止。
- 尚未在 Intel 硬件或最低 macOS 版本上做运行验证。

## 安装或升级

打开 DMG，把 Bingo Send 拖进「应用程序」，也可解压 ZIP。替换前先退出旧版。请亲自在系统
设置中授予辅助功能权限，选择目标应用后再选择运行模式。若旧授权失效，请在辅助功能列表
移除旧条目并重新添加当前的 Bingo Send。

安装包使用 **ad-hoc 临时签名，未经 Apple 公证**；签名变化后可能需要重新授权。
详见[使用指南](USER_GUIDE.zh-CN.md)与[验证记录](VERIFICATION_1.3.4.md)，发布附件包含校验文件。
