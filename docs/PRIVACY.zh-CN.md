# 隐私说明

Bingo Send 不录音、不调用语音识别服务、不发起网络请求、不发送遥测，也不把输入正文写入文件或 UserDefaults。语音输入法、目标应用及 GitHub 自身的数据处理不属于本工具范围。

## 运行时处理

启用后，程序约每 0.25 秒检查前台应用。仅对已启用的应用读取当前聚焦输入框的文本、光标/选区状态、控件可用状态；浏览器页面还可能读取网页地址以建立当前页面上下文。程序已识别的浏览器强制检查允许的域名，无法确认地址或不匹配时，在读取正文前停止；未识别的浏览器请手动启用“按网页域名限制”。

读取的完整文本及页面上下文只用于内存中的口令匹配、防重复和发送前核验。短暂切走焦点时，上一条输入状态可保留最多 3 分钟，以适配语音浮层；停止或重启后不会从磁盘恢复。macOS 授予的辅助功能权限范围比应用内部名单更广，名单限制由本项目代码执行。

发送时向原目标应用发出 Return、Command-Return 或 Control-Return。程序不会改写正文、删除口令、修改选区或读写剪贴板。

## 本机保存的设置

UserDefaults 域为 `io.local.bingosend`，键为 `bingoPreferencesV1`，保存自定义口令、等待时间、检测模式、应用名称和标识、发送快捷键、允许的网站域名等配置。口令本身作为用户配置保存；聊天正文不保存。

窗口中的状态只显示时间、配置中的应用名称和固定错误信息；部分错误含数字范围或系统错误码，不含聊天正文、网页地址或窗口标题。状态不作为历史日志写入磁盘。

## 权限与移除

辅助功能用于读取输入框并发出按键。程序不自动获取权限、不修改系统授权数据库、不请求麦克风或屏幕录制权限。

退出应用可停止检测。卸载时删除应用，并在系统设置中移除其辅助功能授权。若要清除本机设置，先退出，再运行：

```sh
defaults delete io.local.bingosend
```

提交问题时请只提供无隐私的测试句、版本信息和状态提示，不提供真实聊天、凭据、UserDefaults 导出或浏览历史。
